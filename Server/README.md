# User Management REST API

This is a simple REST API built with **Node.js**, **Express**, and **MongoDB** that performs basic CRUD (Create, Read, Update, Delete) operations for user data.

## 🚀 Features
- Add a new user
- View all users
- Get user by ID
- Update user details
- Delete user
- MongoDB database integration using Mongoose

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- Postman (for testing)
